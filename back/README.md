# Elixir - backend

API de Elixir en NestJS + GraphQL. La documentacion completa (instalacion, variables, CI/CD y MCP) esta en el [README principal](../README.md).

Comandos rapidos:

```powershell
npm install
npx prisma generate     # con el servidor detenido
npm run start:dev       # desarrollo
npm run lint            # calidad de codigo
npm test                # pruebas unitarias
npm run test:e2e        # pruebas de integracion
npm run build           # build de produccion
```
